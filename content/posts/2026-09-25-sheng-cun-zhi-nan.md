# 生存指南

2025–2026 年最适合"AI 生成为主、经验不深"的人去接的单，集中在两类：一是**给中小企业搭 AI 自动化/聊天机器人/语音接待**（n8n、Make、Vapi 这类工具拼装），二是**AI 视频/营销内容生产**。

企业最愿意花钱的是看得见、马上能用的 AI 应用。

## 一、推荐方向

### 第一梯队

**1. AI 业务自动化（n8n / Make / Zapier + LLM API）**

- 典型单子：线索抓取后自动写外联邮件、表单进 CRM、发票和文档自动处理、内容发布流水线、客服工单分流。
- 为什么适合你：节点式拼装，AI 写 JS/Python 小段代码、写提示词就够用，不需要架构能力。
- 单价：Upwork 上 n8n 专家 2026 年收费约 $40–100/小时，价差主要看有没有 AI Agent 和 API 集成经验。
- 值得学的商业模式：成熟的 n8n 服务商通常收一次搭建费，再加月度维护费（托管、监控、第三方 API 变动时修复）。维护费是稳定收入的关键。

**2. AI 客服/知识库聊天机器人（WhatsApp、网站、Slack）**

- 典型单子：给诊所、律所、电商、房产中介做 FAQ 机器人、预约机器人、基于文档的问答。
- 分层很明显：Upwork 上初级"平台配置"类约 $25–60/小时，中级 RAG 和集成类 $50–90，资深 LLM 工程师 $90–150+；市场中位数约 $45/小时。

**3. AI 语音接待 / 电话 Agent（Vapi、Retell 等）**

- 典型单子：给中小企业做 AI 前台，接入日历、短信通知和邮件。
- 竞争比聊天机器人少，而且客户（牙医、装修、餐厅）按"少漏接一个电话值多少钱"来算账，更容易接受按项目报价。

**4. AI 视频 / UGC 广告 / 无脸 YouTube 内容**

- 增速最高的方向，而且几乎全靠 AI 工具链（脚本→配音→数字人或生成视频→剪辑）。
- 缺点是单价偏低、竞争者大多是非程序员。你的优势在于能写脚本做**批量化生产流水线**，可以卖"每月 30 条广告素材"这种包月服务，而不是按条卖。

### 第二梯队

5. MVP / 内部工具 / 落地页

- 需求真实（Claude Code 专家需求那 938% 主要就是这类），但要控制范围：只接**小型、边界清楚**的单，比如管理后台、落地页、Chrome 插件、简单 SaaS 原型、Shopify/WordPress 定制。
- 普通 Web 开发价格被压得很低：Upwork 上 Web 开发者中位数约 $30/小时（常见区间 $15–50）。

**6. 数据抓取 + 表格/报表自动化**

- 爬取公开数据、清洗、生成 Google Sheets 报表。AI 写爬虫很擅长，单子量稳定，但单价一般。

## 三、预期参考

| 方向                 | 新手可接受的定价              | 做出口碑后          | 竞争程度           |
| -------------------- | ----------------------------- | ------------------- | ------------------ |
| n8n/Make 自动化      | $25–40/小时或 $300–1,500/项目 | $50–100/小时 + 月费 | 中（在升温）       |
| 聊天机器人（配置类） | $25–45/小时                   | $50–90/小时         | 高                 |
| AI 语音接待          | $500–2,000/项目               | + 月度维护          | 中低               |
| AI 视频/UGC          | $20–50/条或包月               | 包月 $1,000+        | 高（非技术人员多） |
| 小型 Web/MVP         | $15–35/小时                   | $40–60/小时         | 非常高             |

新手期的整体区间可以参考：应用型 AI 技能的新人通常从 $25–60/小时起步，技术和咨询型从 $50–100 起步。

还有一个现实问题：地区定价差异。同样能做 RAG、Agent、n8n 的开发者，外包地区的价格可以低到 $15–25/小时，所以大量同行在跟你拼价格，靠低价是赢不了的。

## 五、风险与平台建议

**Upwork**

- 抽成：2025 年 5 月 1 日起，原来固定 10% 的服务费改成按合同浮动 0–15%，大多数合同实际在 10% 左右。
- 投标成本：额外的 Connects 每个 $0.15，多数投标需要 6–16 个。按 10% 中标率算，新手获客成本不低，所以要精准投标，别海投。
- 封号风险：账号被限制会让之前投入的 Connects 和平台积累全部归零。一定要用真实身份，账号不要多人共用，交付物要确实可用。
- 正面信号：活跃客户数同比降 4%，但单客户支出创新高 $5,230，平均时薪合同达 100 小时。客户在变少但变大，更适合走专业细分路线，而不是低价通吃。

**Fiverr**：更适合把服务做成标准化"套餐"（例如"n8n 线索自动化，3 天交付"）。标题直接用买家在搜的词：n8n automation、AI voice agent、Claude Code、AI UGC ads。

**跨平台共性风险**

1. **交付后维护**：AI 工作流会因为第三方 API 变化而坏掉。合同里写清楚维护范围和费用，这本身就是利润来源。
2. **能力被戳穿**：客户在面试中问技术细节、或交付后要求改动时，完全不懂代码会很被动。建议至少读懂 AI 生成的代码、能自己调试常见错误。
3. **API 成本和 Key 管理**：让客户用自己的 OpenAI/Anthropic 账号和 Key，避免你垫付调用费或承担数据泄露责任。
4. **AI 生成内容的版权和肖像**：AI 视频、UGC 广告不要用真人名人、品牌 logo 或来历不明的素材。
5. **收款**：国内收款一般走 Payoneer 或直接提现到银行卡，要留意提现费和汇损，并按规定申报收入（这部分请以当地规定为准，我不是税务顾问）。

## 六、建议的起步路径

1. **选一个组合深挖**：比如"n8n + AI 语音接待，专做美国本地服务业（诊所、装修、律所）"。细分越窄，越好写提案、越容易复用模板。
2. **先做 3 个作品集 Demo**：录 2 分钟演示视频，说明"帮客户省了多少时间或多接了多少单"。客户买的是结果，不是技术。
3. **低价拿前 5 个好评**，然后逐步涨价，并推出月度维护套餐。
4. **边做边补基础**：HTTP/API、JSON、Webhook、基础 JavaScript/Python、调试。这些学起来不难，但决定你能不能从 $30/小时走到 $70/小时。

---

新人第一个月接不到单，主要原因通常不是假单，而是**新账号没有信任记录，再加上泛泛地海投**。假单确实存在，但靠一套固定的筛选规则就能过滤掉大部分。真正需要花心思的是：把自己包装成"解决某个具体问题的人"，再用 3 到 5 个能在线体验的 Demo 替代你还没有的客户好评。

## 一、假单：分清两类，分别应对

### 第一类：骗钱或骗信息

Upwork 官方列出的典型手法包括：要求转到平台外沟通或付款、要求预付费用、钓鱼消息、礼品卡诈骗。第三方整理的新人陷阱还有：把沟通转到 Telegram 或 WhatsApp、让你先买加密货币或软件工具、发送带恶意程序的"合同"PDF、先付款再用虚假理由申诉退款，以及用假职位收集你的个人信息。

**识别信号**：职位描述模糊、预算和工作量明显不匹配、文案像 AI 生成的套话、在职位里索要个人资料，或者客户是新注册、支付方式未验证、没有雇佣记录。

### 第二类：针对开发者的"面试投毒"

这一类对你威胁最大，因为它专门针对"会运行代码的人"：

- 微软 2026 年 3 月披露了一个叫 Contagious Interview 的攻击活动：攻击者冒充加密货币交易公司或 **AI 解决方案公司**的招聘方，让受害者克隆并运行托管在 GitHub、GitLab 或 Bitbucket 上的 npm 包。
- 它的流程和正常招聘一模一样：联系、技术讨论、布置作业、跟进，恶意代码藏在作业环节。被窃取的是 API Token、云服务凭证、签名密钥、加密钱包和密码管理器数据。
- BBC 2026 年 9 月报道了一个英国案例：求职者做完一份"技术测评"，几小时后加密货币账户里的 18,000 英镑就被清空了。
- 有些恶意代码甚至在用 Cursor 这类 IDE **打开**仓库时就会触发，不一定要等到运行。

**防护规则**：

1. **永远不在主力电脑上运行客户或"面试官"提供的代码**。先在 GitHub 网页上看源码，需要运行时用一次性虚拟机或 GitHub Codespaces。
2. 主力电脑上不放加密钱包，API Key 不写在全局环境变量里。
3. 对方要求"先 review 一下我们的代码库"或"跑一下看看报错"，默认按高风险处理。
4. 用 pnpm 替代 npm：它默认不执行 postinstall 脚本，除非你明确放行。

### 筛选规则

| 检查项                   | 通过标准                                   |
| ------------------------ | ------------------------------------------ |
| 支付验证                 | 必须已验证。这一条单独就能排除大部分风险   |
| 历史消费                 | 有过 $1,000 以上的消费记录更可靠           |
| 描述清晰度               | 写清楚了工具、目标、交付物                 |
| 沟通和付款               | 全部在平台内完成，要求转到平台外就直接放弃 |
| 是否要你先付钱或先装软件 | 是，就放弃                                 |

有数据支持"精准投标"比"海投"更有效：表现最好的服务商每天投不到 12 个标，只投自己有成功案例的细分类目，并且在职位发布后两小时内投出。表现最差的那批每天投三四十个，不挑客户也不看支付状态，回复率只有 2% 左右。

## 二、冷启动

**合理预期**：按专注策略执行的新人，多数在 2 到 6 周内拿到第一单。决定速度的不是才华，而是投标的精准度和速度：每周 10 个高度定制、投给发布不到一小时的职位，通常好过 50 个泛泛的投标。

### Upwork

- **争取 Rising Talent 新人徽章**：它会显示在你的资料和投标里，还附送 30 个 Connects。条件之一是完成 Upwork 的 Readiness Test、保持资料 100% 完整、持续活跃和投标。
- **挑新人能赢的单**：刚开始雇人的客户（更愿意给新人机会）、$50–500 的小项目、需求清晰、投标人数少于 10 个、刚刚发布的职位。
- **在投标里坦白自己是新人**，同时提供一个小的测试任务来降低客户的风险。第一单超额交付，然后主动请客户给五星好评。第一个好评拿到后，第二个客户会容易很多。
- **上架 Project Catalog（固定价格套餐）**：这相当于 Upwork 里的"被动接单"入口，和你想做的品牌化方向一致。

### Fiverr

- 抽成是固定 20%，比 Upwork 高。
- 新 Gig 发布后 24 到 48 小时会得到一段临时曝光；稳定进入第一页通常需要 2 到 6 周。**第一周没排名不要删掉重发**。
- **多个具体的 Gig 比一个大而全的 Gig 效果好**。标题公式：核心关键词 + 细分对象 + 具体结果，控制在 80 个字符以内。

## 三、如何包装

你的真实情况是"没有多年经验，但借助 AI 交付很快"。包装要围绕这个**真实优势**展开，不要伪造资历。

### 1. 定位："帮谁、解决什么、多久交付"

- ❌ `Full Stack Developer | Python | AI | Automation Expert`
- ✅ `n8n & AI Automation for Shopify Stores | Order, Return & Support Workflows`
- ✅ `AI Chatbot for Local Service Businesses | Trained on Your FAQs, Live in 5 Days`

### 2. 个人简介的结构（前两行最重要，客户在列表里只能看到这些）

1. **第一句**：客户的痛点（"你的团队每周要花 10 小时手动处理退货邮件？"）
2. **你交付什么**：3 个具体的套餐或结果
3. **证据**：Demo 链接、演示视频（在没有好评之前，这部分替代好评）
4. **工作方式**：固定价格、异步沟通、交付后 X 天免费修改、维护可选。异步沟通也顺带解决了你的时差和英语口语问题。
5. **行动号召**：请对方发来工作流程截图，你在 24 小时内免费回复一份方案

### 3. 关于"用 AI 做"这件事怎么说

不必隐瞒，也不用刻意强调。把它包装成**交付方式的优势**："AI 加速开发，所以交付更快、价格固定"。客户买的是结果，而现在大多数自由职业者都在用 AI 工具。

**红线**：不要编造工作年限、虚构公司案例或刷评价。平台的身份核查在变严，被判定造假的代价是封号，之前积累的一切清零。

### 4. 投标模板（控制在 150 词以内）

```
Hi [名字]，

[一句话复述对方的具体问题，证明你看懂了需求]

我会这样做：
1. [第一步，写具体的工具或节点]
2. [第二步]
3. [第三步]

这是我做过的类似 Demo（2 分钟视频）：[Loom 链接]

固定价格 $X，[N] 天交付，含 7 天免费修改。
一个问题：[问一个能体现你专业度的澄清问题]
```

**最后那个问题很关键**。它能引导客户回复，而回复率会影响你在平台上的表现。

## 四、该准备哪些开源项目或 Demo

### 选择原则

1. **和你卖的套餐一一对应**：每个 Demo 对应一个 Gig 或 Project Catalog 套餐。客户看到 Demo 就知道能买到什么。
2. **能在线体验 > 能看视频 > 只能看代码**。你的客户（店主、诊所老板、营销经理）大多不看代码。
3. **README 要写得像销售页**：解决什么问题、前后对比、截图或 GIF、30 秒上手步骤、"想要定制版请联系我"。
4. **3 到 5 个精品就够**，不要堆 20 个半成品。
5. **Demo 用虚构的品牌和数据**（比如一家虚构的咖啡店、一个虚构的物业公司），不要冒用真实公司。

### 推荐的 Demo 组合

| #    | Demo                                                         | 展示形式                                                | 对应套餐       |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------- | -------------- |
| 1    | **行业自动化模板包**（比如 Shopify 退货处理：邮件分类 → AI 生成回复草稿 → 写入表格 → Slack 通知） | n8n 工作流 JSON + 2 分钟演示视频；投稿到 n8n 官方模板库 | AI 运营自动化  |
| 2    | **知识库客服机器人**（上传 FAQ 或 PDF → 嵌入网站的聊天窗口，附带简单管理后台） | 在线可以直接聊的 Demo 网站                              | 聊天机器人搭建 |
| 3    | **AI 电话接待 Demo**（一家虚构诊所或餐厅的前台，能回答问题、登记预约） | 一个客户能真实拨打的号码或网页通话 + 通话录音           | 语音接待       |
| 4    | **AI 广告素材批量生产流水线**（产品表格 → 脚本 → 配音 → 视频，批量输出） | 一组成品视频 + 开源脚本                                 | AI 内容订阅    |
| 5    | **"AI 原型上线"起步模板**（登录、支付、邮件、部署一站式配好，附一份上线检查清单） | GitHub 模板仓库 + 在线示例站                            | 原型上线服务   |
| 6    | **AI 可见度检测小工具**（输入品牌名，查询多个模型的回答里是否提到它，生成报告） | 开源小工具 + 一份示例报告                               | GEO 审计       |

| 周次    | 重点                                                         |
| ------- | ------------------------------------------------------------ |
| 第 1 周 | 定下 2 到 3 个套餐方向；搭好一台隔离的开发虚拟机；做出前 2 个 Demo |
| 第 2 周 | 完善 Upwork 资料并上架 Project Catalog；在 Fiverr 发布 3 到 4 个细分 Gig；每天投 3 到 5 个精准标 |
| 第 3 周 | 补齐第 3 个 Demo；根据客户的回复和提问调整标题和投标模板     |
| 第 4 周 | 第一单超额交付并争取好评；把这一单整理成案例（在客户同意的前提下）；开始在行业论坛答疑 |

每周检查一个指标：**投标被查看的比例**。如果很低，说明标题或投标开头有问题；如果被查看了却没回复，说明内容或 Demo 没打动人。
